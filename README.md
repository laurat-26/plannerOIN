# Panel de Seguimiento OIN

Panel web estático para seguimiento visual de tareas OIN.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub, por ejemplo `panel-seguimiento-oin`.
2. Sube estos cuatro archivos a la raíz:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `data.js`
3. Ve a **Settings > Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona `main` y carpeta `/ (root)`.
6. Guarda. GitHub mostrará la URL pública del panel.

## Qué incluye
- Filtros por usuario, estado, bucket y prioridad.
- Indicadores de total, completadas, en curso y vencidas.
- Distribución de carga por usuario.
- Vista individual por responsable.
- Resumen automático para reunión.
- Opción de imprimir la vista de reunión o guardarla en PDF.
